# ماريول (MARIOL)

A retro side-scrolling platformer starring **Omran** — an original pixel-art
Saidi farmer hero (white turban, brown galabeya, maroon shawl, big mustache,
wooden nabboot staff) — in an Egyptian desert world: pyramids, palms,
terracotta jars, scarab enemies, and gold coins.

**Play:** arrows + Space/Enter on desktop, on-screen touch buttons on mobile.

- One full level (World 1-1) with coins, ?-blocks, bricks, jars, gaps,
  staircases, stompable scarabs, 3 lives, timer, score, and a flag finish.
- All art and sound are original work. No Nintendo assets.
- Zero dependencies, zero build: a single static `index.html`.

Deployed on Vercel. Made with Instinct.
